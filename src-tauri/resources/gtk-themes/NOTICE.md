GTK theme base
==============

Matugen Studio bundles adw-gtk3 theme assets as the base for generated GTK
themes.

Upstream: https://github.com/lassekongo83/adw-gtk3
License: LGPL-2.1
License text: LGPL-2.1-only.txt

The generated Matugen GTK themes are derived copies with color definitions
rewritten from the current Matugen palette.
